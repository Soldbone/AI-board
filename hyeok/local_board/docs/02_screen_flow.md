# 화면설계서 / 사용자 흐름

## 1. 문서 목적

이 문서는 Local Board의 주요 화면, 화면 간 이동 흐름, 사용자 액션을 정리합니다.

## 2. 전체 화면 목록

| 화면 | 경로 또는 상태 | 설명 |
| --- | --- | --- |
| 게시글 목록 | list view | 게시글 목록, 검색, 태그 필터, 정렬 |
| 게시글 작성 | create view | 새 게시글 작성, 비슷한 게시글 검색, 태그 추천 |
| 게시글 상세 | detail view | 본문, 댓글, 비슷한 게시글, AI 추천 |
| 게시글 수정 | edit view | 기존 게시글 수정 |
| 로그인 | login view | 로그인 폼 |
| 회원가입 | signup view | 회원가입 폼 |
| 마이페이지 | profile view | 내 정보 수정 |

## 3. 공통 헤더

### 표시 요소

- 서비스명: Local Board
- 로그인 상태 표시
- 로그인 / 회원가입 버튼
- 마이페이지 / 로그아웃 버튼
- 목록 이동 버튼 역할

### 동작

| 액션 | 결과 |
| --- | --- |
| 서비스명 클릭 | 게시글 목록 화면으로 이동 |
| 로그인 클릭 | 로그인 화면으로 이동 |
| 회원가입 클릭 | 회원가입 화면으로 이동 |
| 마이페이지 클릭 | 내 정보 수정 화면으로 이동 |
| 로그아웃 클릭 | 토큰 삭제 후 비회원 상태로 변경 |

## 4. 게시글 목록 화면

### 주요 구성

- 키워드 검색창
- 태그 필터 목록
- 정렬 옵션
- 게시글 목록
- 페이지 이동
- 글쓰기 버튼

### 사용자 흐름

```text
사용자 접속
→ 게시글 목록 조회
→ 검색어 또는 태그 선택
→ 조건에 맞는 게시글 목록 갱신
→ 게시글 클릭
→ 상세 화면 이동
```

### 게시글 카드 표시 정보

| 정보 | 설명 |
| --- | --- |
| 제목 | 게시글 제목 |
| 지역 | 예: 용인 처인구, 창원 성산구, 사당역 |
| 가게명 | 특정 가게 질문일 경우 표시 |
| 분류 | 예: 중식, 카페, 치과 |
| 조회수 | view_count |
| 댓글 수 | comment_count |
| 작성일 | created_at |

## 5. 게시글 작성 화면

### 입력 필드

| 필드 | 필수 여부 | 설명 |
| --- | --- | --- |
| 제목 | 필수 | 질문 또는 후기 제목 |
| 본문 | 필수 | 구체적인 질문 내용 |
| 지역 | 필수 | AI 장소 추천에 사용 |
| 가게명 | 선택 | 특정 가게 질문일 때 사용 |
| 분류 | 선택 | 음식점, 카페, 병원 등 |
| 태그 | 선택 | 쉼표로 구분 |

### 보조 기능

| 기능 | 설명 |
| --- | --- |
| 비슷한 게시글 검색 | 제목/본문/가게명/태그 기준으로 기존 글 추천 |
| AI 태그 추천 | 제목/본문을 기준으로 태그 후보 추천 |

### 사용자 흐름

```text
글쓰기 버튼 클릭
→ 제목/본문/지역 입력
→ 필요 시 가게명/분류/태그 입력
→ 비슷한 게시글 확인
→ 게시글 등록
→ 상세 화면 이동
```

## 6. 게시글 상세 화면

### 주요 영역

| 영역 | 설명 |
| --- | --- |
| 게시글 헤더 | 지역, 분류, 가게명, 제목, 작성일 |
| 본문 | 게시글 내용 |
| 비슷한 게시글 | RAG 기반 추천 결과, 토글로 열고 닫음 |
| AI 추천 | DB 기반 평가와 장소 추천 |
| 댓글 | 댓글/대댓글 목록과 작성 폼 |

### 상세 화면 흐름

```text
게시글 목록에서 글 클릭
→ 게시글 상세 조회
→ 댓글 목록 조회
→ 비슷한 게시글 자동 조회
→ 사용자가 AI 장소 추천 클릭
→ DB 기반 평가 + 장소 추천 표시
```

### 비슷한 게시글 영역

- 기본은 접힌 상태입니다.
- 사용자가 "열기"를 누르면 유사 게시글을 확인합니다.
- 가게명이 있는 게시글은 같은 가게명이 포함된 글만 추천 후보로 사용합니다.

### AI 추천 영역

표시 순서:

```text
DB 기반 평가
→ 장소 추천 리스트
```

### 댓글 영역

| 액션 | 조건 | 결과 |
| --- | --- | --- |
| 댓글 작성 | 로그인 필요 | 댓글 등록 |
| 익명 체크 | 로그인 필요 | 작성자 닉네임 숨김 |
| 답글 작성 | 부모 댓글 존재 | parent_id가 있는 댓글 생성 |
| 댓글 삭제 | 작성자 본인 | 삭제된 댓글로 표시 |

## 7. 게시글 수정 화면

### 진입 조건

- 로그인 사용자
- 게시글 작성자 본인

### 사용자 흐름

```text
상세 화면에서 수정 클릭
→ 기존 게시글 값 표시
→ 내용 수정
→ 저장
→ 상세 화면으로 복귀
```

## 8. 로그인 화면

### 입력 필드

- 이메일
- 비밀번호

### 성공 흐름

```text
로그인 정보 입력
→ 백엔드 로그인 API 호출
→ access_token 저장
→ 현재 사용자 정보 조회
→ 게시글 목록으로 이동
```

## 9. 회원가입 화면

### 입력 필드

- 이메일
- 닉네임
- 비밀번호

### 성공 흐름

```text
회원가입 정보 입력
→ 중복 검사
→ 사용자 생성
→ 로그인 화면 또는 목록 화면으로 이동
```

## 10. 마이페이지 화면

### 기능

- 닉네임 수정
- 소개글 수정

### 사용자 흐름

```text
마이페이지 클릭
→ 현재 사용자 정보 표시
→ 닉네임/소개글 수정
→ 저장
→ 변경된 사용자 정보 반영
```
