# 테스트 계획서

## 1. 문서 목적

이 문서는 Local Board의 주요 기능을 어떤 기준으로 검증할지 정리합니다.

## 2. 테스트 범위

| 범위 | 포함 여부 |
| --- | --- |
| 회원가입/로그인 | 포함 |
| 게시글 CRUD | 포함 |
| 댓글/대댓글 | 포함 |
| 태그/검색/페이징 | 포함 |
| RAG 추천 | 포함 |
| MCP 장소 검색 | 포함 |
| Agent AI 추천 | 포함 |
| 배포 환경 부하 테스트 | 제외 또는 추후 |

## 3. 백엔드 기본 테스트

### 서버 실행

| 항목 | 기대 결과 |
| --- | --- |
| FastAPI 서버 실행 | `http://127.0.0.1:8000/docs` 접속 가능 |
| DB 연결 확인 | `/health` 또는 DB 연결 테스트 성공 |
| CORS | 프론트엔드에서 API 호출 가능 |

## 4. 인증 테스트

| ID | 테스트 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| AUTH-01 | 회원가입 성공 | 새 이메일/닉네임 입력 | 201, 사용자 정보 반환 |
| AUTH-02 | 이메일 중복 | 같은 이메일로 가입 | 오류 반환 |
| AUTH-03 | 닉네임 중복 | 같은 닉네임으로 가입 | 오류 반환 |
| AUTH-04 | 로그인 성공 | 올바른 이메일/비밀번호 | access_token 반환 |
| AUTH-05 | 로그인 실패 | 잘못된 비밀번호 | 오류 반환 |
| AUTH-06 | 내 정보 조회 | 토큰 포함 GET /auth/me | 사용자 정보 반환 |
| AUTH-07 | 토큰 없음 | 토큰 없이 /auth/me 호출 | 401 |

## 5. 게시글 테스트

| ID | 테스트 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| POST-01 | 게시글 작성 | 로그인 후 필수값 입력 | 게시글 생성 |
| POST-02 | 지역 누락 | region 빈 값 | 422 또는 오류 |
| POST-03 | 목록 조회 | GET /posts | 목록과 페이지 정보 반환 |
| POST-04 | 검색 | keyword 입력 | 제목/본문/태그 기준 검색 |
| POST-05 | 태그 필터 | tag 입력 | 해당 태그 글만 조회 |
| POST-06 | 정렬 | sort=views/comments/latest | 조건대로 정렬 |
| POST-07 | 상세 조회 | GET /posts/{id} | 조회수 증가 |
| POST-08 | 게시글 수정 | 작성자가 PATCH | 수정 반영 |
| POST-09 | 수정 권한 없음 | 다른 사용자가 PATCH | 403 |
| POST-10 | 게시글 삭제 | 작성자가 DELETE | 204 |

## 8. RAG 테스트

### 자동 테스트

실행 명령:

```bash
python scripts/check_rag_flow.py
```

현재 포함된 테스트:

| 테스트 | 기대 결과 |
| --- | --- |
| empty input | 빈 입력이면 빈 배열 |
| no result | 매칭 없음이면 빈 배열 |
| top 5 limit | 최대 5개 반환 |
| deleted post excluded | 삭제된 글 제외 |
| store name filter | 가게명이 있으면 같은 가게명 글만 반환 |

### 수동 테스트

| ID | 테스트 | 입력 | 기대 결과 |
| --- | --- | --- | --- |
| RAG-01 | 가게명 기반 추천 | 갑짬뽕 처인구점 | 같은 가게명 글만 추천 |
| RAG-02 | 지역만 있는 추천 | 사당역 카페 | 지역/카테고리 기반 추천 |
| RAG-03 | 불용어 제거 | "어때요", "궁금해요" 포함 | matched_keywords에 일반 질문어 최소화 |
| RAG-04 | 명사 추출 | "처음 가보려는데 괜찮을까요" | 가게명/지역/분류 위주 추출 |

## 12. 테스트 데이터 검증

실행 스크립트:

```bash
python scripts/seed_real_place_test_data.py
```

기대 결과:

| 항목 | 기대값 |
| --- | ---: |
| posts | 250 |
| comments | 약 999 |
| tags | 약 238 |
| 용인 처인구 | 50 |
| 창원 성산구 | 100 |
| 사당역 | 100 |

주의:

- 스크립트 실행 시 기존 게시글/댓글/태그 데이터가 삭제됩니다.
- 실제 가게명은 네이버 지역검색 API 기반입니다.
- 댓글은 발표용 샘플입니다.
