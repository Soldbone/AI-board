# AI Recommendation Handoff

## 이번 단계의 핵심 개념

AI 추천 기능은 세 가지 흐름으로 나눠서 보면 이해하기 쉽다.

1. 추천 생성
   - 사용자가 게시글 상세 또는 직접 재료 입력에서 추천을 실행한다.
   - 로그인한 사용자만 실행할 수 있다.
   - 하루 실행 횟수 제한은 없다. OpenAI API 키가 있으면 실행한 만큼 비용이 발생할 수 있다.

2. 추천 저장과 조회
   - 추천 결과는 저장된다.
   - 게시글에 붙은 추천은 게시글 상세에서 공개 조회할 수 있다.
   - 내가 실행한 추천은 마이페이지의 AI 추천 기록에서 볼 수 있다.

3. 추천 근거
   - 추천은 단순히 메뉴명만 저장하지 않는다.
   - AI가 참고한 댓글 답변이 있는 게시글도 함께 저장해서, 왜 이 추천이 나왔는지 추적할 수 있게 한다.
   - 질문글 본문은 상황 정보이고, 실제 커뮤니티 근거는 댓글의 조리 팁이나 답변이어야 한다.

## 상태값을 보는 방법

AI 추천 상태는 사용자에게 세 가지 의미로 보여주는 것이 좋다.

- 대기중: 아직 이 게시글에 추천 기록이 없다.
- 완료: 현재 게시글 기준으로 사용할 수 있는 추천이 있다.
- 다시 추천: 게시글이나 댓글이 바뀌어서 기존 추천이 오래된 상태다.

중요한 점은 목록, 검색 결과, 내 게시글, 상세 화면이 같은 기준을 써야 한다는 것이다.
한 화면에서는 완료로 보이고 다른 화면에서는 대기중으로 보이면 사용자가 기능을 믿기 어렵다.

## pgvector 흐름

pgvector는 게시글 임베딩을 PostgreSQL 안에 vector 타입으로 저장하고, DB가 직접 유사한 게시글을 찾게 하는 방식이다.

현재 방향은 다음과 같다.

1. 게시글과 댓글, 태그를 묶어 추천용 문서 텍스트를 만든다.
2. 문서 텍스트를 임베딩으로 바꾼다.
3. 임베딩을 pgvector 컬럼에 저장한다.
4. 추천 요청이 들어오면 요청 대상 임베딩과 가까운 게시글을 pgvector로 찾는다.
5. 유사도가 기준값 이상이고, 보유 재료와 최소한의 재료 연결이 있으며, 댓글 답변이 있는 게시글만 실제 근거로 인정한다.
6. 추천 결과와 참고 게시글을 저장한다.

## 참고 게시글이 없을 때

첫 게시글이거나 비슷한 글이 아직 없으면 pgvector 검색 결과가 0개일 수 있다.
검색은 되었지만 유사도가 낮거나 재료 연결이 없거나 댓글 답변이 없으면 참고 게시글로 쓰지 않는 것이 맞다.
이 경우 추천 생성을 멈추지 않고 `GENERAL_AI` 모드로 저장한다.

- `COMMUNITY_RAG`: 비슷한 커뮤니티 게시글을 1개 이상 참고한 추천
- `GENERAL_AI`: 참고 게시글 없이 현재 글 또는 직접 입력 내용과 일반 요리 지식으로 만든 추천

`GENERAL_AI` 추천에서는 AI가 커뮤니티 글을 참고했다고 말하면 안 된다.
화면에서도 "현재 내용과 일반 요리 지식 기준"이라는 안내가 보여야 한다.

이 구조에서 OpenAI API 키가 있으면 OpenAI 임베딩과 추천 생성을 사용할 수 있고,
키가 없으면 비용이 들지 않는 로컬 흐름으로 서비스가 끊기지 않게 유지한다.

## 지금 기억할 점

- 로컬 PostgreSQL 이미지는 pgvector 지원 이미지여야 한다.
- DB에 `vector` 확장이 설치되어 있어야 실제 pgvector 검색이 가능하다.
- 기존 배열 임베딩은 pgvector 컬럼으로 전환되었다.
- 기존 RAG 문서는 다음 추천 실행 때 새 vector 임베딩으로 다시 채워진다.
- fallback은 품질 개선 대상이 아니라, pgvector 환경이 아직 준비되지 않았을 때 기능이 완전히 죽지 않게 하는 안전장치다.
- 참고 게시글이 없는 추천은 실패가 아니라 `GENERAL_AI` 모드의 정상 결과다.
- `AI_RECOMMENDATION_MIN_SIMILARITY` 값으로 문맥 유사도 기준을 조정할 수 있다. 기본값은 `0.55`다.
- `AI_RECOMMENDATION_MIN_INGREDIENT_OVERLAP` 값으로 최소 재료 겹침 기준을 조정할 수 있다. 기본값은 `1`이다.
- 재료 겹침은 유사도 점수를 올리는 가산점이 아니라, 엉뚱한 참고글을 제외하는 필터다.
